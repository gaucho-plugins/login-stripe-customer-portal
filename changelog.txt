= 1.0.6 =
* Security: redirect URL setting is now persisted correctly (1.0.5 silently failed to save).
* Security: magic-link URLs honor the configured Customer Portal slug instead of a hardcoded path.
* Security: stored magic-link tokens are now SHA-256 hashed at rest.
* Security: settings page enforces manage_options; every wp_die() message is HTML-escaped.
* Security: per-email + per-IP rate limiter (5 / 10 min) on magic-link issuance.
* Security: form response wording is mode-aware and constant for valid/invalid/unknown emails (no enumeration oracle, no misleading "if registered" wording when validate-existing is off).
* Security: Secret Key input renders a fixed-length mask (no length leak).
* Security: customer portal slug is now length-capped (max 64 chars) to prevent rewrite-engine bloat.
* Security: namespaced Exception catch fixed — Stripe failures now render a graceful message instead of WSOD.
* UX: settings description now explicitly notes that unchecking the existing-customers toggle auto-creates a Stripe customer on first redemption.
* a11y: shortcode forms now use per-instance unique `id` attributes so embedding the shortcode multiple times on one page no longer produces duplicate IDs.
* a11y: front-end form uses `<label for>`, `autocomplete="email"`, `required`.
* Privacy: plugin uninstall now cleans up every option and transient (Stripe Secret Key no longer lingers in wp_options after uninstall).
* Privacy: GDPR personal-data exporter and eraser registered with WordPress Privacy Tools.
* Reliability: new daily WP-Cron sweep removes expired magic-link tokens and rate-limit counters.
* Ops: new WP-CLI commands — `wp lscp purge-tokens`, `wp lscp limiter-reset <email>`, `wp lscp send <email>`, `wp lscp config`.
* Reliability: 250 PHPUnit tests, 18,690 assertions, property-based fuzz, token-entropy distribution, concurrent-redemption race, CRLF/email-header hardening, slug path-traversal hardening.
* Compatibility: minimum PHP bumped to 7.4 (PHP 7.0–7.3 are end-of-life). Backwards-compatible LSCP\Plugin public surface preserved.
* Internal: refactored into focused units (Settings, TokenStore, TokenGC, StripeGateway, Mailer, RateLimiter, PortalController, FormRenderer, RewriteEndpoint, Shortcode, Privacy, Cli, Uninstall, DocsHelper).
* Privacy: new uninstall.php cleans up every option and transient on plugin delete — your Stripe Secret Key no longer lingers in wp_options after uninstall.
* Privacy: GDPR personal-data exporter and eraser registered with WordPress Privacy Tools.
* Reliability: new daily cron sweep proactively removes expired magic-link tokens (WP's transient GC is otherwise lazy).
* Reliability: 240+ PHPUnit tests, 18,000+ assertions, property-based fuzz on the token store, token-entropy distribution check, concurrent-redemption race test.
* Ops: new WP-CLI commands — `wp lscp purge-tokens`, `wp lscp limiter-reset <email>`, `wp lscp send <email>`, `wp lscp config`.
* Compatibility: backwards-compatible LSCP\Plugin public surface preserved.
* Internal: refactored into focused units (Settings, TokenStore, TokenGC, StripeGateway, Mailer, RateLimiter, PortalController, FormRenderer, RewriteEndpoint, Shortcode, Privacy, Cli, Uninstall, DocsHelper).
